# 0.2.3 英文測試按鈕版面修正

## 專案概況

HyperOS 勿擾白名單是使用 libxposed API 102 的 LSPosed 模組，可為選定 App 保留勿擾下的通知聲音、震動與橫幅，並為各 App 選擇自動亮屏或系統側邊光效。設定介面支援繁體中文、簡體中文及英文，以及系統深色模式與動態主題色。
