# 0.2.6 通知控制、鎖屏效果與快捷操作

## 本次完整修改

- 勿擾例外依 Android 使用者、套件及通知頻道判斷，關閉勿擾時回歸系統原判斷。
- 每個 App 可選自動亮屏、系統側邊光效、跟隨系統，或不亮屏且無側邊光效。修正被取消的頻道、群組摘要及靜默更新造成的鎖屏提醒，加入 HyperOS AOD 動畫路徑過濾。
- 每個 App 的允許聲音、允許震動直接放在鎖屏選項下方，按儲存套用。舊設定預設允許兩者，仍尊重系統音量與頻道設定。
- 通知類別直接按名稱勾選，重複名稱顯示 ID，提供 Root 讀取備援與進階手動輸入。
- 改善設定服務重連、前景重新同步、背景序列儲存、失敗後顯示、舊版模式預設值及空應用清單重試。
- 新增目前使用者的 JSON 匯出與合併匯入，提供新增、衝突及未安裝項目預覽。備份格式版本 3 支援舊格式，包含聲音、震動、鎖屏模式及頻道規則。
- 新增兩個系統程序的相容性診斷、取樣耗時與錯誤計數，診斷通訊使用簽章權限。反射依執行期類別快取，重複錯誤限流。
- 測試通知顯示來源、勿擾與對照狀態，檢查測試頻道音效、震動與重要性。
- 首頁新增月亮勿擾圖示與放射狀快速重啟圖示，跟隨主題色並提供無障礙及長按提示。勿擾開啟採優先通知模式。快速重啟可選系統介面、桌面、設定、安全服務及全選。
- 補齊繁體中文、簡體中文及英文介面、深色模式與動態主題色的操作說明。
- README 更新完整安裝、操作、備份、Root 使用、相容性、隱私與建置方式。逐份檢查 UPDATE_SUMMARY 並一般化個人測試資料，排除裝置識別、網路位址、私人頻道值、私訊內容及本機路徑。
- 版本為 0.2.6，versionCode 13，套件名稱 io.github.de0921188.dnd.whitelist。

## 驗證

- Release 建置及 lint 通過，27 項單元測試通過，0 項失敗。
- 正式 APK 使用既有憑證簽署並完成驗證。
- 實機確認通知聲音、震動、自動亮屏與不亮屏且無側邊光效的組合。使用者確認個別播放開關測試正常。
- 通知類別取消與恢復勾選可在無重開機下生效。已實測 SystemUI 快速重啟與 Hook 重新載入，月亮按鈕可關閉再開啟勿擾。
- 桌面、設定、安全服務的實際重啟與其他 ROM 的行為需個別驗證。最新所有變更下的完整桌面橫幅矩陣尚未重測。
