# 0.2.8 通知類別規則與診斷

## 通知類別

- 新增「允許所有類別」與「只允許所選類別」兩種範圍。指定類別模式可保留空清單，舊版空清單沿用允許所有類別。
- 每個類別可覆寫自動亮屏、側邊光效、跟隨系統或暗屏，以及聲音和震動。通知規則仍依 Android 使用者、App 及類別判定。
- 系統框架與 Root 備援都能列出對話子頻道。清單顯示父子關係、系統重要性、鈴聲與震動，並可打開系統通知頻道設定。保留手動輸入頻道 ID。
- 匯出格式升至 4，涵蓋類別放行模式、父子頻道關係與獨立提醒覆寫。合併預覽比對新增欄位，可匯入版本 1–3 的舊備份。

## 診斷與相容性

- 儲存設定時一併寫入規則版本，設定頁、系統框架與 SystemUI 可分別回報版本。診斷亦顯示兩個系統程序的勿擾狀態、讀取錯誤與各提醒功能所需的 Hook。
- 可針對指定 App 啟用兩分鐘的通知追蹤，查看規則命中、聲音與震動路徑、群組與更新判定以及鎖屏模式，並從實際觀測到的通知開啟類別設定。
- 診斷報告可預覽與複製。可複製的內容排除通知文字、套件名稱與原始頻道 ID。播放路徑與實際提醒在驗證時分別核對。
- AOD 外掛 Hook 安裝成功後才標記完成，首次失敗可在後續讀取時有限次重試。
- 補齊繁體中文、簡體中文與英文的類別編輯和診斷字串。README 更新至 0.2.8，涵蓋啟用、相容性、備份及診斷。

## 驗證與發布

- 版本 0.2.8，versionCode 15。Release 建置及 29 項單元測試通過，lint 0 項錯誤、10 項警告。新增測試涵蓋舊有空清單語意、指定類別空清單、父子繼承與單項覆寫。
- 使用既有正式憑證，驗證簽章、套件版本與 APK 內容。實機就地升級後核對設定保留，重新啟動後確認系統框架與 SystemUI 載入模組。
- 實機分別觸發兩種真實通知事件。勿擾開啟且鎖屏時，系統頻道開啟對應提醒後，兩種通知都確認自動亮屏、聲音與震動。系統頻道關閉震動時，實機仍可亮屏與發聲。
