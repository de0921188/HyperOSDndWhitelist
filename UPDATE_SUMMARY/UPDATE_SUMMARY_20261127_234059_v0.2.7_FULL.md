# 0.2.7 勿擾快捷開關修正

## 全部未提交修改

- 版本由 0.2.6 升至 0.2.7，versionCode 14。
- 新增 Root 執行入口 DndCommand，透過系統通知服務切換勿擾，處理不同系統 API 簽章。修正自動規則生效時一般切換指令回傳成功但狀態未改變的問題，關閉時暫停當前規則，保留排程設定。
- 勿擾開啟顯示太陽，關閉顯示月亮；點按切換開關。新增太陽向量圖示，沿用主題色、長按提示及無障礙標籤。
- 以實際勿擾狀態驗證指令結果，保留退出碼、錯誤輸出、逾時與讀回狀態診斷。
- 更新繁體中文、簡體中文及英文失敗提示，涵蓋系統勿擾設定及 Root 授權。
- 更新脫敏 README 的版本、使用方式及實機驗證結果。
- 將 UPDATE_SUMMARY 合併為本單一時間戳文件，涵蓋此前 0.2.6 的通知類別、獨立聲音震動、四種鎖屏模式、AOD 過濾、備份合併、診斷及快捷操作，及本次勿擾修正。
- 公開文件排除裝置識別、網路位址、個人排程、私訊內容、私有頻道值、本機路徑、設定備份及簽章材料。

## 驗證

- Release 建置、27 項單元測試與 lint 通過，單元測試 0 失敗。
- 正式 APK 使用既有憑證簽署，已完成簽章驗證。
- 修正程式已在實機確認可關閉勿擾。使用者另確認單擊雙向切換及太陽、月亮顯示正常。
- 保留 0.2.6 已驗證的通知功能，其他 ROM 私有 API 行為仍需個別確認。通知完整矩陣本輪未重測。
