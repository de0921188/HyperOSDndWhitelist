# HyperOS 勿擾白名單 0.2.2 完整專案摘要

## 專案功能

- Android LSPosed 模組，套件名稱為 com.qing.dnd.whitelist，讓指定 App 的通知在 HyperOS 勿擾模式下保留聲音、震動及橫幅提醒。
- 獨立設定頁提供總開關、App 搜尋與白名單；每個 App 可分別選擇自動亮屏或沿用系統側邊光效。
- 自動亮屏沿用系統鎖屏和防誤觸條件；側邊光效使用系統既有樣式。支援深色模式與系統動態主題色。
- 提供延遲測試通知及設定說明；模組不強制開啟關閉或靜音的通知頻道、不調整音量。

## 架構與設定

- 使用現代 libxposed API 102 與官方設定服務，LSPosed 作用域為 system 和 com.android.systemui。
- 系統框架與 SystemUI 攔截通知判斷；遠端設定包含總開關、App 白名單及各 App 模式。設定服務不可用時不放行勿擾限制。
- 保留一次性舊設定匯入機制；不同 Android 使用者及工作設定檔不自動共用白名單。
- Android minSdk 31、targetSdk 36、compileSdk 37；使用 Gradle wrapper、JDK 及 Android SDK 建置。
